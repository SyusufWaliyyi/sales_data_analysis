# Phone and Accessories data analysis

A data analysis for an electronic store in Nigeria with sales outlets in five cities to answer the following questions.



\#📊 \*Sales Data Analysis Project — Questions\*



✅ Revenue Overview



1\. What is the total revenue generated?

2\. What is the average order value?

3\. How many total orders were placed?



✅ Product Analysis



4\. Which products generate the highest revenue?

5\. Which products perform the worst?

6\. How much revenue does each category generate?

7\. Based on the data, which ONE product should the company invest more in?





✅ City Performance



8\. Which city generates the highest revenue?

9\. Which city generates the lowest revenue?

10\. What is the average order value for each city?

11\. Should the company expand operations in the top-performing city?



✅ Payment Behavior



12\. Which payment method is used most frequently?

13\. What percentage of transactions comes from each payment method?

14\. How much revenue is generated by each payment method?

15\. Should the company consider removing cash payments?



✅ Advanced Analysis



16\. Which city–product combination generates the highest revenue?

17\. What is the average quantity purchased per order?

18\. What percentage of total revenue does each product contribute?

19\. Create an order size classification (Small, Medium, Large). Which group generates the most revenue?

20\. Who are the top 5 customers by total spending?



⭐ Visualization Tasks



21\. Create a chart showing revenue by product.

22\. Create a chart showing revenue by city.

23\. Create a chart showing payment method distribution.
